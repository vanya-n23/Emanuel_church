# Изображения для новостей

Поместите сюда изображения для новостной ленты:

- `service-december.jpg` - Недільне богослужіння
- `christmas-kids.jpg` - Різдвяна програма для дітей  
- `prayer-evening.jpg` - Молитовний вечір
- `christmas-carols.jpg` - Різдвяні колядки

## Рекомендации по изображениям:

- **Размер:** 1200x800px (соотношение 3:2)
- **Формат:** JPG или WebP
- **Размер файла:** до 500KB для быстрой загрузки
- **Качество:** высокое, но сжатое

## Альтернативные источники:

Пока нет реальных изображений, можно использовать:
- Unsplash.com (поиск: church, prayer, community)
- Placeholder изображения: `https://via.placeholder.com/1200x800/f8f9fa/333333?text=News+Image`
- Создать изображения с помощью AI генераторов
